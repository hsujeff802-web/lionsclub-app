龍興會智慧管理系統 V2.0.4 愛心基金永久保存修正版
日期：2026-08-07

本版修正：
1. 修正 localStorage 容量滿時，畫面看似已儲存但 F5 後資料消失。
2. 永久保存改以 IndexedDB 為主要儲存，localStorage 只保留一份主資料。
3. 移除 V2.0.3 會重複保存多份完整資料的 lionsclub_* 副本，避免再次爆滿。
4. 還原資料時改以「最近保存時間」優先，不再以資料筆數多寡判斷，避免舊資料蓋回新資料。
5. 登出備份不再把完整備份塞進 localStorage，只下載 JSON 備份檔。
6. 新增「愛心基金備份還原（V2.0.4）」：可匯入 龍興會_愛心基金備份_日期.json，採合併＋去重，不覆蓋其他模組。
7. Service Worker 快取版本更新，GitHub Pages 更新後較不容易讀到舊 JS。

8月愛心基金救援方式：
- 開啟系統 -> 點「愛心」
- 最上方會看到「愛心基金備份還原（V2.0.4）」
- 按「匯入愛心基金備份」
- 選擇 2026-08-06 或更新的愛心基金 JSON 備份
- 匯入後系統會顯示新增幾筆、8月共有幾筆
- 接著按 F5 測試，資料應仍保留

GitHub Pages 更新：
- 將本資料夾內全部檔案上傳覆蓋 repository 根目錄
- Commit 到 main
- 等 Pages 部署完成後，在網站按 Ctrl+F5 一次
