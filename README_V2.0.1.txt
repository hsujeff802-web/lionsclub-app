LionsClub V2.0.1 財務愛心資料永久保存修正版

修正：
1. 財務報表按「儲存表格」後，同時寫入 LocalStorage 與 IndexedDB。
2. 愛心基金按「儲存表格」後，同時寫入 LocalStorage 與 IndexedDB。
3. 關閉程式、關閉瀏覽器或重新開機後，重新開啟會恢復上次資料。
4. 程式關閉前會再自動保存一次。
5. 如果主資料遺失，會從第二份保存資料自動恢復。
6. 保留備份匯入、管理員密碼、報表修改與月份結轉功能。

測試：
- 輸入一筆財務資料並按儲存表格
- 輸入一筆愛心基金並按儲存表格
- 關閉所有程式視窗
- 重新開啟同一資料夾的 OPEN_PC.html
- 資料應該仍然存在

電腦請開 OPEN_PC.html
手機請開 OPEN_MOBILE.html
